Kost-In: Room Rental Management System

Context
Assistant recruitment project, Basic Computing Laboratory, Telkom University
Role
Developer
Period
Apr 2023

Background

Kost-In is a C program for managing kos (boarding house) rentals, built as part of the recruitment process to become a teaching assistant at the Basic Computing Laboratory. It simulates the system from two sides, the owner (admin) and the tenant (user), with a flow from booking to payment.

Admin features

  • View registered accounts: monitor every user registered on the system.
  • View room bookings: see booked rooms and their availability.
  • Set payment reminders: configure a reminder for the rent due date.
  • Set prices: set the rental price for each room type.

User features

  • Choose a room type: Premium or Standard, with an optional laundry subscription.
  • Choose a kos type: mixed, male-only or female-only.
  • Check the total cost and choose a payment option (BCA, BRI or QRIS).
  • Leave a review that other prospective tenants can read before booking.

Implementation

The program is written entirely in C, using struct to store account and room data and file handling to keep data between sessions. Interaction is through a menu-driven console interface with separate logins for admin and user.

Through this project I was selected as a C Programming teaching assistant at the Basic Computing Laboratory.
